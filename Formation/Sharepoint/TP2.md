# TP 2 — Création d’une bibliothèque documentaire

## Contexte

Le service RH souhaite stocker ses documents administratifs dans SharePoint.

---

## Objectifs pédagogiques

- Créer une bibliothèque de documents
- Configurer les paramètres essentiels
- Ajouter des dossiers
- Comprendre le fonctionnement documentaire SharePoint

---

# Partie 1 — Réalisation

## Étape 1 — Créer la bibliothèque

1. Ouvrir le sous-site RH
2. Cliquer sur **Contenu du site**
3. Cliquer sur **Ajouter une application**
4. Choisir **Bibliothèque de documents**

Nom de la bibliothèque :

**Documents RH**

---

## Étape 2 — Configurer la bibliothèque

1. Ouvrir l’onglet **Bibliothèque**
2. Cliquer sur **Paramètres de la bibliothèque**

Modifier les paramètres suivants :

|   |   |
|---|---|
|Paramètre|Valeur|
|Gestion des versions|Activée|
|Approbation de contenu|Désactivée|
|Affichage dans la navigation|Oui|

---

## Étape 3 — Créer des dossiers

Créer les dossiers suivants :

- Contrats
- Recrutement
- Procédures

---

# Résultat attendu

La bibliothèque doit :

- Être visible dans le menu de gauche
- Contenir les dossiers demandés
- Conserver les versions des documents

---

# Correction détaillée

## Gestion des versions

Lorsque la gestion des versions est activée :

- Chaque modification d’un document est enregistrée
- Il est possible de restaurer une ancienne version
- Les utilisateurs peuvent consulter l’historique

---

## Point pédagogique

Une bibliothèque SharePoint ne sert pas uniquement à stocker des fichiers.

Elle permet aussi :

- La traçabilité
- La recherche avancée
- Le partage sécurisé
- La collaboration documentaire
