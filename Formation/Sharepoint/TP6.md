# TP 6 — Création d’une page SharePoint avec WebParts

## Contexte

Le service RH souhaite disposer d’une page d’accueil centralisant les informations importantes.

---

## Objectifs pédagogiques

- Créer une page SharePoint
- Ajouter des WebParts
- Organiser des contenus

---

# Partie 1 — Réalisation

## Étape 1 — Créer la page

1. Cliquer sur **Paramètres**
2. Cliquer sur **Ajouter une page**
3. Nommer la page :

**Accueil RH**

---

## Étape 2 — Ajouter des WebParts

Ajouter les composants suivants :

|   |   |
|---|---|
|WebPart|Fonction|
|Bibliothèque Documents RH|Affichage documentaire|
|Éditeur de contenu|Texte d’accueil|
|Liens récapitulatifs|Navigation rapide|

---

## Étape 3 — Organiser la page

- Déplacer les WebParts
- Modifier leur taille
- Ajuster la disposition
- Enregistrer la page

---

# Résultat attendu

La page d’accueil RH doit :

- Afficher les documents importants
- Fournir des liens rapides
- Améliorer la navigation utilisateur

---

# Correction détaillée

## Les WebParts dans SharePoint 2016

Les WebParts sont des composants réutilisables permettant de construire des pages dynamiques.

Ils permettent notamment :

- D’afficher des documents
- D’afficher des listes
- D’intégrer du contenu HTML
- De créer des tableaux de bord

---

## Point pédagogique

Une bonne page SharePoint doit rester :

- Simple
- Lisible
- Rapide à comprendre
- Orientée utilisateur
