# TP 4 — Création d’affichages personnalisés

## Contexte

Le service RH souhaite afficher uniquement les documents validés.

---

## Objectifs pédagogiques

- Créer un affichage personnalisé
- Filtrer les données
- Masquer les dossiers

---

# Partie 1 — Réalisation

## Étape 1 — Créer un affichage

1. Ouvrir la bibliothèque Documents RH
2. Cliquer sur **Créer un affichage**
3. Sélectionner **Affichage standard**

Nom de l’affichage :

**Documents validés**

---

## Étape 2 — Configurer le filtre

Créer le filtre suivant :

|   |   |   |
|---|---|---|
|Colonne|Condition|Valeur|
|Statut|Est égal à|Validé|

---

## Étape 3 — Masquer les dossiers

Dans la section Dossiers :

Sélectionner :

**Afficher tous les éléments sans dossiers**

---

# Résultat attendu

L’affichage doit montrer uniquement les documents validés.

---

# Correction détaillée

## Ce qu’il fallait comprendre

Les affichages SharePoint permettent de créer plusieurs lectures métier d’une même bibliothèque.

Par exemple :

- Documents validés
- Documents archivés
- Documents par service
- Documents récents

---

## Point pédagogique

Un affichage n’efface pas les données.

Il s’agit simplement d’une manière différente de présenter les informations.
