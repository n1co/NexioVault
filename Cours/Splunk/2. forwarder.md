## ⚙️ 2. Configurer l’agent pour pointer vers ton Splunk Windows

### a. Se connecter à l’agent

`cd /opt/splunkforwarder/bin`

### b. Démarrer et accepter la licence

`sudo ./splunk start --accept-license`

### c. Configurer le forward-server (ton Splunk sur Windows)

Remplace `<IP_SPLUNK>` par l’adresse IP de ton serveur Splunk Windows et `9997` par le port d’écoute (par défaut 9997).

`sudo ./splunk add forward-server <IP_SPLUNK>:9997 -auth admin:motdepasse`

_(le mot de passe ici est celui du compte admin de ton Splunk Windows)_

---

## 📄 3. Choisir les logs à envoyer

### Exemple : envoyer les logs système Debian

`sudo ./splunk add monitor /var/log`

Tu peux aussi cibler un fichier spécifique :

`sudo ./splunk add monitor /var/log/syslog`

---

## 🚀 4. Activer le démarrage automatique

`sudo ./splunk enable boot-start`
