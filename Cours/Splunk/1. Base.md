## **Indexer des fichiers et répertoires via l’interface Web**

Une fois Splunk accessible :

1. Connectez-vous à l’interface.
    
2. Cliquez sur **Add Data**.
    
3. Sélectionnez **Upload** > _From Files_.
    
4. Choisissez un fichier de logs, par exemple `access.log`.
    
5. Créez un nouvel **index** (ex : `web_logs`).
    
6. Lancez l’indexation.
    

Splunk va lire le fichier, découper les événements, et les rendre immédiatement consultables via son moteur de recherche SPL.

> 🧩 **Exemple pratique :** indexez un dossier contenant les logs Apache et explorez les événements en recherchant `status=404` pour identifier les erreurs de page introuvable.


### correlation user/ip

```
index=*
| rex field=_raw "for (?<user>\w+) from (?<src_ip>\d{1,3}(?:\.\d{1,3}){3})"
| stats count BY user src_ip
| sort - count
```

### failed puis sucess

```
index=*
| rex field=_raw "(?i)(?:for|user=)(?<user>\w+).*(?:from|rhost=)(?<src_ip>\d{1,3}(?:\.\d{1,3}){3})"
| eval result=if(match(_raw,"Failed password|authentication failure"),"failed","success")
| stats count BY src_ip user result
| sort - count
```
